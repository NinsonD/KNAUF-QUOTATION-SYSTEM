# System drawings

These 31 drawings were extracted from the user-supplied `Knauf Costing Sheets.xls` workbook. `src/data/system-images.json` maps each of its 19 worksheets to the app's 14 system codes, using each worksheet's embedded Office drawing image references.

Vector drawings were rendered at a higher resolution; raster drawings retain their original resolution. WebP assets use lossless encoding. Shared images remain shared where the workbook uses the same drawing (including KW625/KWB626 and KW116 with/without head deflection). They are shown as reference illustrations; the selected quotation's material list determines its specification.

# Official Knauf system illustrations

The gallery uses 12 images fetched directly from `media.knauf.com` on 2026-10-14. `src/data/system-images.json` records each original asset URL, official Knauf source page, image dimensions, and mapping notes for all 14 app systems and 19 base/head variants.

UAE system images cover the partitions, shaft wall and CW/CD/adhesive wall linings. KC_B001, KC_A001 and KC_A001_FR use the UAE KC001 family framework illustration; it does not establish a fire-rated suspension specification. D127 uses Knauf Spain's D127 illustration. The legacy workbook KWA611 (direct metal furring) uses Knauf Spain's W622.es omega lining illustration, expressly labeled as a construction reference rather than an exact UAE system-code match. It is not mapped to UAE KW611, which is adhesive-bonded lining.

The official overview pictures do not show head-deflection connections. Head variants clearly state this and link to the relevant official system page. Exact board types, profile sizes, spacing and head details remain determined by the quotation items and approved design. Source images are stored as received from Knauf's image service, without retouching or AI generation. Images remain copyright Knauf.
